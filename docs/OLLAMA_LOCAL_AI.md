# الذكاء المحلي لعارف

يتيح عارف إجابات ذكية من المعرفة المسموح بها للمستخدم حتى عند انقطاع الإنترنت. يستخدم التطبيق Ollama محلياً عبر `127.0.0.1:11434` فقط؛ لا تفتح المنفذ `11434` في الجدار الناري ولا تضبطه على عنوان عام.

## خادم 204

العنوان الذي ظهر على شبكة العمل هو `10.10.10.204`. عند الفحص في 28-08-2026 كان المنفذ `22` غير متاح، لذلك لا يمكن تنفيذ التثبيت عن بُعد قبل إعادة خدمة SSH أو فتحها من شبكة الإدارة فقط.

بعد إتاحة SSH، نفّذ على الخادم من حساب له صلاحية `sudo`:

```bash
ssh adham@10.10.10.204
cd /path/to/Workflow-PNCECS
git pull --ff-only
chmod +x scripts/install_ollama_local_ai.sh
./scripts/install_ollama_local_ai.sh qwen2.5:3b
```

السكربت يثبت Ollama بالطريقة الرسمية عند الحاجة، يشغّل خدمته، ينزّل النموذج، ويحدّث ملف `.env` للتطبيق. بعد اكتماله أعد تشغيل خدمة عارف المعتادة، ثم تحقق من النموذج محلياً على الخادم:

```bash
curl --fail http://127.0.0.1:11434/api/tags
```

## جهاز التطوير

بعد تثبيت Ollama على Windows، نزّل النموذج:

```powershell
ollama pull qwen2.5:3b
```

ثم أضف إلى `.env`:

```dotenv
ASSISTANT_LOCAL_AI_ENABLED=1
ASSISTANT_LOCAL_AI_URL=http://127.0.0.1:11434/api/chat
ASSISTANT_LOCAL_AI_MODEL=qwen2.5:3b
ASSISTANT_LOCAL_AI_TIMEOUT=90
ASSISTANT_LOCAL_AI_CONTEXT_CHARS=12000
```

أعد تشغيل عارف بعد تغيير `.env`. إذا تعذر تشغيل Ollama أو النموذج، يبقى عارف على رده المحلي المنظّم ولا يرسل معرفة النظام إلى خدمة خارجية.
